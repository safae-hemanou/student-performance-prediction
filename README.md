# Student Performance Prediction Using Apache Spark MLlib

## Project Overview

This project focuses on predicting students' final grades using academic indicators and machine learning techniques.

The model uses three input features:

* Study hours
* Number of absences
* Class participation level

The target variable is the student's final grade.

## Technologies Used

* Python
* PySpark
* Apache Spark MLlib
* Google Colab
* Linear Regression

## Project Workflow

1. Load and explore the dataset.
2. Prepare the data using PySpark.
3. Assemble input features using `VectorAssembler`.
4. Split the dataset into training (80%) and testing (20%) sets.
5. Train a linear regression model.
6. Evaluate predictions using Root Mean Square Error (RMSE).
7. Predict the final grade for a new student.

## Objective

The objective is to demonstrate how machine learning can be used for predictive analysis in an educational context.
